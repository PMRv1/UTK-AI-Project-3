# AI-Driven Data Analysis with Prompt Engineering
➔ Uses the Hugging Face Inference API and the Qwen2.5-72B-Instruct model to analyze financial data through prompt engineering instead of traditional machine learning.

➔ Loads CSV datasets from Google Drive and feeds them into structured prompts to generate insights, identify patterns, and predict stock prices based on variable relationships.

➔ Cleans the model responses to extract valid CSV formatting and converts them into structured Pandas dataframes for downstream evaluation.

➔ Compares actual versus predicted stock prices across various companies and generates Matplotlib visualizations to highlight performance trends.

➔ Provides comprehensive line-by-line documentation for all workflow steps including data loading, prompt design, output parsing, and visualization.
